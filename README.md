# windlesscastle-website

Static support and privacy pages for the **Windless Castle** iPhone game, served by
GitHub Pages at <https://windlesscastle.murilomarinho.info/>.

- `index.html`: support page (the App Store "Support URL")
- `privacy.html`: privacy policy (the App Store / TestFlight "Privacy Policy URL")
- `CNAME`: the custom domain. DNS: a `CNAME` record `windlesscastle` -> `mmmarinho.github.io`.

The game itself lives in [mmmarinho/withcasles](https://github.com/mmmarinho/withcasles).
Plain HTML, no build step: edit the files and push to `main`.
